# Interatividade: indicadores e tempo

O painel não se resume a gráficos estáticos. Foram encontradas cinco tabelas de parâmetros de campos com referências NAMEOF:

| Parâmetro | Papel no relatório |
| --- | --- |
| pr.Oportunidade | Seleção de indicadores de oportunidade |
| pr.Negociação | Seleção de indicadores de negociação |
| pr.Contratos | Seleção de indicadores de contratos |
| pr.Calendário | Seleção da granularidade temporal |
| pr.Ciclos | Seleção de indicadores de acompanhamento/ciclo |

As imagens mostram seleções como diagnósticos agendados e realizados, demo/compromisso, propostas, contratos enviados, assinados e pagos, além de ano, trimestre e mês.

Um parâmetro de campos permite ao usuário escolher o campo ou a medida apresentada no visual. Isso é diferente de apenas filtrar linhas de uma tabela.

## Exemplo de uso

A liderança seleciona um trimestre, escolhe contratos assinados e observa sua evolução. Em seguida, troca o indicador para contratos pagos, conservando o contexto temporal para comparar as duas leituras.

A mudança de indicador não deve ser descrita automaticamente como mudança do tipo de gráfico. As evidências confirmam seleção de medidas/eixos; a troca do tipo visual por marcadores não foi validada.

## Apresentação pública

Os exemplos de seleção podem ser demonstrados com capturas revisadas ou uma gravação com dados fictícios. A versão documental não executa essas interações no GitHub.
