# Escopo público e validação

Este repositório contém documentação e exemplos selecionados, não uma cópia do projeto original.

## Incluído

- Contexto e fluxo comercial.
- Diagramas e inventário dos relacionamentos.
- 33 medidas DAX com identificadores internos substituídos.
- Exemplos M adaptados e demonstração com dados fictícios.
- Orientações para capturas revisadas.

## Reservado

PBIX, PBIP, definições completas, identificadores do CRM, credenciais, dados de clientes, valores comerciais e capturas originais.

## Verificação

Os inventários foram obtidos dos arquivos de definição. A seleção foi revisada para evitar inclusão de credenciais e dados reais. Links locais e presença dos arquivos são conferidos na preparação.

Não foram executadas chamadas à API ou cálculos no Power BI Desktop. Cardinalidade declarada não comprova unicidade dos dados. A leitura de filtros em execução e a medida de ciclo negativo precisam de validação no ambiente.

## Cuidados com futuras alterações

O .gitignore auxilia o uso de Git, mas não bloqueia envios manuais pelo navegador. Alterações em arquivos públicos ficam no histórico dos commits.
